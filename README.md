# 🔴 YouTube Studio Pro Max

Brauzerda ishlaydigan **bepul video montaj dasturi**. O'rnatish shart emas.

## Qanday ochish
1. `youtube-studio-pro-max/index.html` faylini yuklab oling
2. **Google Chrome** yoki **Edge** brauzerida oching

## Imkoniyatlar
- 🎞️ Timeline: video, rasm, sarlavha, subtitr, musiqa, diktor ovozi
- ✂️ Kesish, surish, nusxa, orqaga qaytarish (Ctrl+Z)
- 🗣️ Ovozdan matnga → SRT (Whisper, bepul, kompyuterda ishlaydi)
- ⌨️ Matndan ovozga: o'zbek, koreys, rus, ingliz (MMS-TTS, bepul)
- 🧬 Ovoz klonlash (Chatterbox, Hugging Face bepul server — kunlik limit bor)
- 🎙️ Mikrofondan diktor ovozi yozish
- 🎵 Audio vizualizator: ovozga qarab o'ynaydigan ustunchalar (6 uslub: ustuncha, ko'zgu, LED ekvalayzer, tog', to'lqin, aylana)
- 🎨 Rang effektlari, logotip, 12 ta subtitr uslubi
- 🎬 Eksport: Full HD, 4K, Shorts (9:16)
- 💾 Loyiha avtomatik saqlanadi
